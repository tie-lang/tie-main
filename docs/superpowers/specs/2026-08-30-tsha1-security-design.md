## 1. 安全目标表（与 SHA-3 同输出位档对齐，且可量化更优）

记 `L48 = log2(48) ≈ 5.5849625`。TSHA1(msg, n) 的：

- 名义输出位 `k = n·L48`；
- 内部状态位 `s = 32·W`（f/b/x，W=⌈n·L48/32⌉）或 `s = 16·log2(3)·W_r`（r）；
- **有效安全位 = min(k, s) = k**（由 state-per-n 构造保证 s ≥ k ⇒ 无任何封顶/缺口）；

| TSHA1 档 | 名义输出位 | 实得碰撞界 | 实得前像界 | 对齐 SHA-3 | 同档差值 |
| --- | --- | --- | --- | --- | --- |
| n=48 | 268 | 2^134 | 2^268 | SHA3-256（256/2^128） | +6 bit |
| n=69 | 385 | 2^192.7 | 2^385 | SHA3-384（384/2^192） | +0.7 bit |
| n=92 | 514 | 2^256.9 | 2^514 | SHA3-512（512/2^256） | +0.9 bit |

- 位长集合（在 state-per-n spec 集合之上）新增 **n=69 与 n=92**（档位输出位 ≥ SHA-3 同档）；
- 其它位长（2..144）同理：实得 = 名义输出位，位于 SHA-3 对应档位之间。

"更好"的三个可量化维度（均纳入测试面）：

1. **档位输出位 ≥ SHA-3 同档**：碰撞/前像界逐档压过（上表差值）；
2. **无容量缺口**：SHAKE 式"输出长但安全被容量封顶"的缺陷不存在——s ≥ k 恒成立；
3. **次安全性质齐全**：无长度扩展（counter-MD 填充 + 64 位计数器）、base48 截断/取整
   语义一致、常量与实现可复现、纯 tie 零 unsafe。

## 2. 容量语义（b/x 海绵轨显式化）

- 对 b（三轨）与 x（四轨）的海绵轨（轨 C）明确定义：**rate = 消息吸收区、capacity =
  其余全部 C 字**；容量位 `c = (C - rate)·字宽`。
- 吸收/置换/耦合语义按 state-per-n 通用规则执行（§3.3），**不改变算法**；
  本设计仅把 c 写入文档作为安全陈述：`实得安全位 = min(k, s)`，且 s 已含海绵 capacity 全量参与。
- 声明（可复核，非证明）：输出截断不引入 SHAKE 式缺口；XOF 已随 state-per-n 移除，
  不存在"扩展安全封顶"路径（"不足拒绝"）。

## 3. 次安全性质声明（照搬/确认）

| 性质 | 状态 | 依据 |
| --- | --- | --- |
| 碰撞抵抗 = 输出位一半 | 声明并测试 | 构造 s≥k |
| 前像/二前像 = 输出全位 | 声明并测试 | s≥k 且计数器注入 v[1]/v[9] |
| 抗长度扩展 | 声明并测试 | 纯零填充 + 64 位计数器 t 逐块注入，无 0x80/长度后置 |
| XOF/前缀一致性 | 已随删除无此面 | state-per-n §5 |
| 常量可复现 | 已实现 | SEED + SHA-256 计数器流 |
| 恒时性 | 观察项（不承诺） | 全位运算无分支，仍需逐平台评估 |

## 4. 测试面（新增验证探针）

在 state-per-n 重构波内随 KAT 一并落地（tests/tsha_probe/）：

1. **雪崩实验**：64 字节块翻转 1 位 → 摘要 ≥ ~k/2 位翻转、相关性抽样（断言位翻转率
   ∈ [0.45, 0.55]×k，容差采样窗口）。
2. **差分均匀性抽样**：固定输入差分 δ，统计输出差分分布（抽样断言非峰值集中；仅
   作为构造健康度指标，不作安全证明）。
3. **无长度扩展确认**：构造 (msg ‖ pad) 无法由 h(msg) 直接续算（计数器注入语义校验）；
   断言"扩展链"与"直接哈希"结果不等。
4. **全零/全一/单字节边界**：新增 n ∈ {69, 92} 的直方/边界向量，并入 len_probe。
5. **档位对齐探针**：n=48/69/92 输出长度与"有效位 = 名义位"断言（b48 往返 +
   base16 换算一致）。
