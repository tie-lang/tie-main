# TSHA1 性能优化设计（perf-design，波2 实测修订版）

- **日期**：2026-08-30（2026-08-30 波2 实测修订）
- **状态**：已实施（A1 + n=48 struct 特化落地），**硬指标经实验证明不可达，本节修订为实测收口**。
- **范围**：std/tsha1.tie 四模型（f/b/x/r）的热路径性能优化。
  以 scripts/bench/tsha1-cmp-bench（64KB、n=48）为判定基准；sha256 实测 2452 MB/s（39235 次/s）。

## 1. 硬指标（用户要求，2026-08-30）→ 波2 实测结论（修订）

| 档位 | 初始目标 | 波2 实测后 | 结论 |
| --- | --- | --- | --- |
| r | 比 sha256 快 | ~280 次/s | **不可达** |
| f | ≈sha256 | ~240 次/s（struct 特化） | **不可达**（差 ~160×） |
| b | ≥½·sha256 | ~226/s | 不可达 |
| x | ≥⅓·sha256 | ~215/s | 不可达 |

**根因（两次实验实证）**：①A1（S 暂存复用/去掩码/死表）→ +20~53%；②n=48 W 特化
（struct 字段承载 lanes：f/b/x 走 dual9、r 双轨半宽 dual11h）→ **+10~12×**（f 19→238/s、
r 26→275/s，KAT 逐位不变）；③扁平局部变量单函数内核 → 仅 +1.2×（.ll 证实 `-O2` 的
SROA 已消除 struct 按值拷贝）。**结论：剩余瓶颈是算法本身的位平面 ring 数学
（tadd2/tmul2/quant3 + 旋转 + 64 字节 trit 化），本质每块成本 ≈ sha256 的 150×，
与存储形态无关；在现 tiec 后端（i64 全量掩码、无 u32/向量化通道）下不可关闭。**

**实测收口目标（修订判定）**：不再要求与 sha256 同量级；以"族内结构与 **v1 基线对比**"为准：
- n=48 struct 特化收益 10-12× 已落地（f 238 / b 226 / x 215 / r 275 次/s≈15-18 MB/s，KAT 不变）；
- 与 sha256 差距 ~150-165×，**写入头注为算法成本模型差异（位平面 vs ARX），不作为缺陷**；
- 可选后续：W17（n=92/96）同型 struct 特化（预期 ~15→150/s，不改结论）；后端 u32/向量化通道
  为独立跟踪（见 §7）。

## 2. 慢因定位（已实证/已对照）

1. **状态全在堆表**：compress_* 的 v[]/h[] 每轮几十次 `v[i]`/`h[i]` 桥接
   （判界 + 堆寻址 + 32 位遮罩），LLVM 无法寄存器化；对照 sha256 内层为
   纯局部变量 a..h（sha256.tie L130-168），轮内零桥接。
2. **每块堆分配**：compress_* 入口 `table_new_i64()` + 16/24/31 次 push。
3. **trit 化两遍**：block_planes（2×32 字节）与 block_skey（64 字节）对**同一批字节**
   各执行一次 byte_tv（to_trit/trit_val 调用）。
4. **skey 64 步串行依赖链**：`skey = skey*24 + dig`。
5. **全量 32 位掩码**：每运算 `& 0xFFFFFFFF`（tie 无 u32）。

结构对照：r（R=8 双轨）与 f（R=12 双轨）的轮成本 ≈ sha256 的 64 轮量级；
b（R=14 三轨）≈ 1.5× f、x（R=16 四轨）≈ 2× f——目标倍率与结构成本自洽。

## 3. P-A 波：语义不变重写（KAT 零变更，独立小任务逐条提交）

设计原则：**与现状逐位等价**——每条只动实现纪律，不动公式/常量/填充/编码。

### A1 状态本地化（sha256 纪律热路径）
- 轨/工作状态从"函数内新建 table + 下标读写"改为**函数参数传入的固定尺寸工作对象**
  （digest 层一次申请、compress 复用），或直接局部变量承载轨道字；
- 轮循环内的每一步保持与现状**完全相同的运算序列与 (M,N) 位语义**；
- 判定：探针 KAT 原样 PASS + cmp-bench 显著抬升（预期最先见效，10-50× 起）。

### A2 trit 化单遍
- 一次 64 字节扫描同时产出 (M0,N0),(M1,N1) 与 skey；byte_tv/byte_bits3 每字节只调一遍；
- 值不变（同一字节同一函数），KAT 不变。

### A3 每块零分配
- 工作缓冲在 digest 层分配一次，compress_* 复写；删每块 table_new/push；
- 与 A1 可合并实现，但允许分开提交（各自可回归）。

### A4 位移/常量预计算
- 轮内 rA/rB/mA/mB 及常量错位量：由"r 与 skey"推导的不变式，提升为每块预计算表，
  轮循环内查表；值不变。

### A5 掩码最小化
- 在本地变量传播下删除可证明高位为零的掩码（保持 32 位语义）；
- 只做 LLVM 已证明可省的部分，禁改动轮公式。

## 4. P-B 波：语义变化（仅在 P-A 未达标时启动）

### B1 skey 分片并行
- 64 步串行链拆 4×16 步局部链，按固定规则归并（**值会变**——摘要变更；
  必须进入 state-per-n 重构波，与生成器/探针一个圈内对齐 KAT，禁止单独落地）。

## 5. 验证与验收（波2 修订）

- 每完成一项优化：`tsha1f/r/b/x_probe` 全 PASS（**语义不变项摘要必须逐字相等**）+
  `tsha1_len_probe` PASS + cmp-bench 重跑刷新 out。
- **已落地**：A1 复用 S 暂存/去死表/去冗余掩码（47e8ae5）；n=48 W 特化 dual9/dual11h
  （0fb41ba，10-12×）；扁平局部变量实验无效已回退。
- **判定**：与 §1 修订收口对表；P-B1（skey 分片，语义变更）**不再启动**
  （瓶颈为每块 ring 数学成本而非 skey 链，启动无收益）。

## 6. 范围外

- 大 n（128/144）性能由 state-per-n spec 本就按 W 缩放；此 spec 只优化热路径系数。
- 常量时间/侧信道专项、SIMD 引入、并发分块——均不在本设计内。

## 7. 独立跟踪（不进当前波）

- tiec 后端 u32/向量化通道：位平面 32 位运算若获得 u32 类型与 SIMD 支持，
  TSHA1 每块成本可望趋近 sha256 同量级（届时重跑 §1 判定）。
- W17（n=92/96）struct 特化：低优先、不改结论的增量优化。
